| NF01 | Printplaat bevestigen |
| Omschrijving | De printplaat moet tijdens alle bewegingen met de maximale productsnelheid veilig bevestigd blijven. |
| Rationale | Voor het uitvoeren van de werkzaamheden is het belangrijk dat de printplaten niet van de robotarm vallen, zodat de prints of printplaten niet kapot gaan. |

| NF02 | Veiligheid |
| Omschrijving | De robotarm mag tijdens normale beweging geen printers of rekken raken. |
| Rationale | Als de robotarm printers of rekken raakt, kunnen deze, of de printplaat die op dat moment aan de robotarm is bevestigd beschadigd raken. |

| NF02 | Snelheid |
| Omschrijving | De robotarm moet tussen twee punten binnen het beweegbereik kunnen bewegen binnen 30 seconden |
| Rationale | Om te zorgen dat alle werkzaamheden optijd uitgevoerd kunnen worden, moet de robot een minimale snelheid hebben die hierbij past. |

| NF03 | Printplaten bij printer houden |
| Omschrijving | Het systeem moet voor minimaal 2 printers bij kunnen houden welke printplaten bij welke printer horen. |
| Rationale | Er word binnen dit project rekening gehouden met een opstelling van 2 printers. Om dit succesvol uit te voeren moeten de printplaten dus bijgehouden worden voor deze twee printers. |

| NF04 | Posities bepalen |
| Omschrijving | Het systeem moet minimaal 4 posities kennen: printer 1, printer 2, schoon rek, gebruikt rek |
| Rationale | Om alle gewenste werkzaamheden uit te kunnen voeren moet de robot heen en weer bewegen tussen de 2 printers, het rek met de schone printplaten en het rek met de gebruikte printplaten. |

| NF05 | Veilige positie |
| Omschrijving | Wanneer de robotarm zich in de veilige positie bevind moet de robotarm buiten bereik van de printers en rekken zijn. |
| Rationale | Voor taken als resin bijvullen moet de werknemer soms nog bij de printers zijn. Hiervoor moet de robotarm de weg naar de printers dus niet versperren. |

| NF06 | Printopdrachten inladen |
| Omschrijving | Het systeem moet teminste 4 printopdrachten kunnen opslaan |
| Rationale | Omdat het doel van dit systeem is om 2 cycli met 2 printers te kunnen printen moeten er minimaal 4 printopdrachten kunnen worden opgeslagen voor later gebruik. |

| NF07 | Geschikte printers |
| Omschrijving | Het systeem moet op basis van resintype, resin hoeveelheid, of er een schone printplaat in hangt en huidige status een geschikte printer kiezen. |
| Rationale | Om te zorgen dat de prints worden toebedeeld aan een printer die geschikt is voor de printopdracht moeten deze parameters gecontroleerd worden. |

| NF08 | Printerstatus opvragen |
| Omschrijving | Het systeem moet binnen 30 seconden de status van 2 printers kunnen opvragen |
| Rationale | Om te zorgen dat de werkzaamheden uitgevoerd kunnen worden is het belangrijk dat het opvragen van de printerstatus niet onnodig lang duurt. |

| NF09 | Opdrachten sturen naar robotarm |
| Omschrijving | De robotarm moet binnen 1 minuut beginnen aan de taken die toegestuurd zijn door het systeem. |
| Rationale | Om te zorgen dat de prints door kunnen blijven gaan is het belangrijk dat het systeem niet onnodig lang blijft wachten op de uitvoering door de robotarm. |

| NF10 | Systeem status informatie |
| Omschrijving | Het dashboard moet weergeven of de printers bezig zijn met een print, klaar voor een nieuwe print, het resin type per print, de hoeveelheid resin en de takenwachtrij weergeven.  |
| Rationale | Om het systeem inzichtelijk te houden voor de printfarm operator is het belangrijk dat deze toezicht op deze aspecten kan houden. |

| NF11 | Print pauzeren |
| Omschrijving | Wanneer de printoperator het printproces pauzeerd moet de robotarm binnen 3 minuten naar de veilige positie gaan. |
| Rationale | Het is geen noodstop, dus het hoeft niet gelijk te gebeuren, maar de werknemer moet eventuele werkzaamheden rondom de robotarm wel binnen redelijke tijd kunnen uitvoeren |

| NF12 | Print hervatten |
| Omschrijving | Het systeem moet binnen 3 minuten de werkzaamheden hervatten wanneer op de knop gedrukt wordt.  |
| Rationale | Als het systeem onnodig lang blijft hangen na het pauzeren kunnen de werkzaamheden van het systeem niet optijd worden uitgevoerd. |

| NF13 | Printqueue weergeven |
| Omschrijving | Er moeten minimaal 4 prints in de printqueue weergegeven kunnen worden. |
| Rationale | Omdat er zelfstandig geprint moet kunnen worden voor 2 cycli met 4 printers moeten er dus 4 opdrachten zichtbaar in de wachtrij kunnen staan. |
